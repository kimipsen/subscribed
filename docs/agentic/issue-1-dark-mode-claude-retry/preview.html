Palette and contrast

The token values and contrast pairs are listed in design.md §5.4–§5.5. The ratios were hand-computed during design. The implementation's automated contrast test (T-C) checks them and fails the build on any pair below 4.5:1 for text or 3:1 for UI and focus.

Accessibility: native labelled <select>; 44 px targets in the real app; the notice is an <output> with Dismiss; switching never moves focus.
