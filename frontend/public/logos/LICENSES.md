# Logo licences

Every file in this folder needs a row in the table below. A backend test fails when a file has no row, or when a `logo` path in
`catalog.json` points at a file that is not here.

Ship no brand logo unless its licence is confirmed. Services without a logo show an initial-letter fallback. Payment option brands without a licensed logo use `generic-card.svg`.
